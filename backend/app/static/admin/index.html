Server setup needed

Sign-in is switched off until the server has a secret key. On the server, add this to /root/clientfinder.ai/backend/.env and restart the API:

JWT_SECRET=<paste the output of: python3 -c "import secrets; print(secrets.token_urlsafe(48))">

Create your admin account

On the server run scripts/admin_cli.py setup-code. It prints a one-time code. Enter it here with your email and a password.

Turn on two-factor sign-in. Scan this with an authenticator app (Google Authenticator, 1Password, Authy…), then enter the 6-digit code it shows.
